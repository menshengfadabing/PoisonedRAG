# 防毒效果可视化展示方案

> 目标：通过直观的可视化图表，展示 PoisonedRAG 三阶段防护系统对各类投毒攻击的检测效果。

---

## 一、整体架构

```
投毒语料库 (180 条)
    ↓
批量攻击模拟测试
    ↓
MetricsCollector 收集结果
    ↓
Streamlit 可视化面板  ← 本方案的核心
```

**技术选型：**
- **前端**：Streamlit（项目已使用） + `pandas`（已安装） + `plotly`（新增依赖）
- **数据源**：`tests/security/test_protection_performance.py` 的测试框架 + `tests/utils/metrics.py` 指标收集器
- **图表库**：`plotly`（交互式图表）+ `streamlit` 原生组件（指标卡、进度条）

## 三、各模块详细说明

### 模块 1: 核心指标卡片

**展示内容：** 6 个核心 KPI 指标，以大号数字卡片形式展示

| 指标 | 计算公式 | 来源 |
|------|---------|------|
| **拦截率** | `被拦截的投毒样本数 / 投毒样本总数` | `PerformanceMetrics.poison_block_rate` |
| **检出率** | `Stage 1 检出的投毒样本数 / 投毒样本总数` | `TestMetrics.detection_rate` |
| **误杀率** | `被误判的正常文档数 / 正常文档总数` | `PerformanceMetrics.false_positive_rate` |
| **召回率** | `正常检索召回的文档数 / 总查询数` | `PerformanceMetrics.normal_recall_rate` |
| **平均耗时** | `总测试时间 / 测试样本数` | `PerformanceMetrics.avg_time_per_query` |
| **测试样本数** | `投毒样本 + 正常样本总数` | 测试框架统计 |

### 模块 2: 各阶段拦截分布

**图表类型：** 堆叠柱状图（Plotly）

**数据来源：** `TestMetrics.stage_breakdown`（ingest_detections / retrieval_blocks / generation_flags）

**维度：**
- X 轴：三阶段 + 漏检
- Y 轴：样本数量 / 百分比
- 颜色编码：Stage 1 (绿色) → Stage 2 (蓝色) → Stage 3 (橙色) → 漏检 (红色)

**交互：** 鼠标悬停显示详细数量、样本 ID 列表

### 模块 3: 各投毒类型检出率

**图表类型：** 水平条形图（Plotly）

**数据来源：** `TestMetrics.poison_type_stats`

**维度：**
- Y 轴：投毒类型（按检出率排序）
- X 轴：检出率百分比
- 颜色：按检出率渐变（红→黄→绿）
- 标注：每条显示具体数值和检测到的样本数

### 模块 4: 隐蔽等级对比

**图表类型：** 分组柱状图

**数据来源：** `TestMetrics.stealth_level_stats`

**维度：**
- X 轴：低 / 中 / 高 三个隐蔽等级
- Y 轴：检出率
- 分组：可叠加显示各隐蔽等级的拦截阶段分布

### 模块 5: 防护模式对比

**图表类型：** 分组柱状图（多指标对比）

**数据来源：** `TestE2EProtection` 的 `standard` / `strict` / `performance` / `disabled` 模式测试结果

**维度：**
- X 轴：四种防护模式
- Y 轴：百分比
- 分组：拦截率（主） + 误杀率（次） + 平均耗时（次）

### 模块 6: 领域覆盖检测率

**图表类型：** 雷达图（Plotly）

**数据来源：** `multi_domain_samples.json` 的 `target_domain` 字段 + 测试结果

**维度：**
- 轴：编程 / 金融 / 医疗 / 法律 / 教育 / 日常生活 / 网络安全
- 值：各领域检出率
- 目标线：标注期望最低检出率（如 80%）

### 模块 7: 风险分数分布

**图表类型：** 小提琴图 或 箱线图（Plotly）

**数据来源：** `ChunkReviewResult.risk_score`（Stage 1）+ `FilterResult.risk_score`（Stage 2）+ `ValidationResult.confidence`（Stage 3）

**维度：**
- X 轴：安全文档 / 投毒文档
- Y 轴：风险分数
- 叠加散点：标注个别异常样本

### 模块 8: 详细检测报告

**图表类型：** Streamlit 数据表格（`st.dataframe`），支持筛选、排序、搜索

**数据来源：** 完整测试结果的 `ProtectionTestResult` 列表

**列：** 样本 ID | 投毒类型 | 隐蔽等级 | 目标领域 | 拦截阶段 | 风险分数 | 置信度 | 结果

**交互功能：**
- 按投毒类型筛选
- 按隐蔽等级筛选
- 按拦截阶段筛选
- 按风险分数排序
- 点击样本查看详细内容

### 4.3 数据流

```
1. 用户点击"运行测试"按钮
   ↓
2. 调用 test_protection_performance.py 中的测试逻辑
   ↓
3. 对所有投毒语料（180 条）+ 正常语料进行模拟攻击测试
   ↓
4. MetricsCollector 收集每个样本的检测结果
   ↓
5. 将结果保存到 st.session_state.test_results
   ↓
6. 各图表模块从 session_state 读取数据并渲染
```

    metrics = MetricsCollector()
    # 加载投毒语料
    # 加载正常语料
    # 逐个测试...
    # 保存结果
    st.session_state.test_results = metrics.to_dict()

def render_dashboard():
    """渲染可视化仪表板"""
    results = st.session_state.test_results
    if not results:
        st.info("请先点击「运行测试」按钮")

    df = pd.DataFrame(results["raw_data"])

    render_domain_coverage_chart(results)
