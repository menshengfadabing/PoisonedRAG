 语料过滤器 和 结果校验器 实现原理                                                                                                        
                          
  1. ContentFilter (语料过滤器)                                                                                                            
                                                                                                                                           
  filter.py:38-287                                                                                                                         
                                                                                                                                           
  三层过滤机制：  

  ┌──────────────┬──────────────────────────────────────────────────┬──────────────────┐
  │     层次     │                     检测方式                     │     风险贡献     │
  ├──────────────┼──────────────────────────────────────────────────┼──────────────────┤
  │ 关键词检测   │ 正则匹配敏感词列表                               │ 每个关键词 +0.3  │
  ├──────────────┼──────────────────────────────────────────────────┼──────────────────┤
  │ 恶意模式检测 │ 字符串匹配预定义恶意模式（如"请忽略之前的指令"） │ 每个模式 +0.4    │
  ├──────────────┼──────────────────────────────────────────────────┼──────────────────┤
  │ 语义异常检测 │ 使用 Embedding 计算与恶意模式的余弦相似度        │ 直接加相似度分数 │
  └──────────────┴──────────────────────────────────────────────────┴──────────────────┘

  核心流程：
  1. filter_text() - 过滤纯文本，计算风险分数 (0.0-1.0)
  2. filter_document() - 扩展过滤文档，额外检查来源可信度
  3. 判定逻辑：risk_score < 0.5 且无警告 → 安全

  来源可信度检查：
  - 遍历 trusted_sources 配置列表
  - 来源字符串包含可信来源关键词即为可信
  - 不可信来源：风险 +0.2，标记不安全

  2. ResponseValidator (结果校验器)

  validator.py:41-351

  三层校验机制：

  ┌────────────────┬──────────────────────┬──────────────────────────────────────────────┐
  │     检查项     │       实现方式       │                     说明                     │
  ├────────────────┼──────────────────────┼──────────────────────────────────────────────┤
  │ 安全规则匹配   │ 正则表达式           │ 检测密码泄露、危险命令、恶意链接、绕过指令等 │
  ├────────────────┼──────────────────────┼──────────────────────────────────────────────┤
  │ 事实一致性检查 │ 语义相似度 / Jaccard │ 验证响应与检索文档的一致性                   │
  ├────────────────┼──────────────────────┼──────────────────────────────────────────────┤
  │ 置信度评估     │ 多因子计算           │ 综合安全性、一致性、响应长度、文档数量       │
  └────────────────┴──────────────────────┴──────────────────────────────────────────────┘

  安全模式检测：
  - 密钥泄露：password/api_key/secret_key/token = xxx
  - 危险命令：rm -rf、format C:、DROP TABLE
  - 可疑链接：.exe/.bat/.sh 下载链接
  - 绕过指令：ignore previous/disregard above

  一致性检查（两种模式）：
  1. 语义模式（有 Embedding 模型）：
    - 计算响应向量与文档向量的余弦相似度
    - 平均相似度 ≥ 阈值 (默认 0.5) → 一致
  2. 简单模式（无 Embedding）：
    - 提取关键词，计算 Jaccard 相似度
    - 阈值 0.1

  置信度计算因子：
  confidence = 1.0
  × 0.3  (如果 is_safe=False)
  × 0.5  (如果 is_consistent=False)
  × 0.7  (响应<10字符) 或 ×0.9 (响应>2000字符)
  × min(1.0, 0.7 + 0.1 * doc_count)
  × 0.6  (无检索文档)

  ---
  设计特点

  1. 可扩展性：两者都支持动态添加关键词/模式
  2. 降级处理：无 Embedding 时使用简单文本匹配作为备选
  3. 风险量化：输出数值分数而非二元判定，便于阈值调优
